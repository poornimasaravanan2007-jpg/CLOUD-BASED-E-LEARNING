About

Cloud-Based E-Learning Platform

This platform is a full-stack cloud computing project built with HTML, CSS, Vanilla JavaScript, and Google Firebase. It demonstrates real-world cloud services including Firebase Authentication, Cloud Firestore (NoSQL database), Firebase Storage, and Firebase Hosting — built as part of a college-level Cloud Computing curriculum.
